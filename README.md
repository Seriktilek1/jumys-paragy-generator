# Жұмыс парағы промпт-генераторы

Мұғалімге арналған құрал. Параметрлерді таңдайсыз — дайын промпт бірден құрылады.
Оны кез келген AI құралына (Claude, ChatGPT т.б.) көшіріп, жұмыс парағын жасатуға болады.

**Ашық сілтеме:** https://seriktilek1.github.io/jumys-paragy-generator/

## Параметрлер
- Жұмыс парағының түрі (тапсырма, деңгейлік, алгоритм, ақпарат, бақылау, рубрика, өзін-өзі тексеру)
- Пән / тақырып және сынып (1–11)
- Формат (А4 тік/жатық, 9:16, 16:9, 1:1)
- Визуалды стиль
- Қиындық деңгейі және мазмұн тілі
- Қосымша нұсқаулар

Бір файлдан тұрады: `index.html` — ешқандай орнату қажет емес.
